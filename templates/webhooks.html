DocuSign Connect

Real-time status updates

When something happens to an agreement — sent, viewed, signed, or declined — DocuSign automatically notifies your systems. No one has to refresh a dashboard or re-type status into FI$Cal.

For program staff, admins, and secretaries: Connect is DocuSign’s notification service. You give IT a web address (endpoint). DocuSign sends a small JSON message each time an envelope changes status — so your contract register, ERP, or case tracker stays in sync automatically.

Security — HMAC verification
Why it matters

IT verifies each POST really came from DocuSign using a shared secret — not a spoofed request.

# Header from DocuSign: X-DocuSign-Signature-1: <hmac_sha256_hex> # Verify in Python: import hmac, hashlib def verify(secret, payload, sig): expected = hmac.new( secret.encode(), payload, hashlib.sha256 ).hexdigest() return hmac.compare_digest(expected, sig)
ℹ
Set WEBHOOK_SECRET in your .env. DocuSign may send up to 5 signature headers — match at least one.
Delivery & retries

If your endpoint returns an error (non-2xx), DocuSign retries with exponential backoff — up to several attempts over hours. Check the Connect failure log in Admin.
