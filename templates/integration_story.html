Connect · Embed · Write-back

Keep people in your systems. Keep status honest.

DocuSign doesn’t have to be a separate destination. Host applications can present signing in-context, trigger Workflow Builder processes with record data, and subscribe to Connect webhooks so status and documents return to the system of record. App Center connectors often deliver these patterns out of the box; custom embed and Connect work fills the gaps.

01

Embedded signing

Using recipient views (and patterns like Power Automate’s embedded signing URL), agencies can present the DocuSign signing ceremony inside a portal, Power App, or custom UI — while the Certificate of Completion still lives in DocuSign.

Agency portal
Keeps the signer in context · eSignature API recipient view / connector patterns
02

Workflow Builder from the record

Workflow Builder (formerly Maestro) workflows can be triggered with mapped inputs from CRM, ITSM, Power Automate, or custom apps — so intake, approvals, and envelope generation follow one governed process instead of a one-off script per system.

  • Trigger via Workflow Builder API / connectors
  • Pass record data as workflow trigger inputs
  • Monitor instance status; write outcomes back with Connect or native writeback
Reusable process definitions · API-triggered instances
03

DocuSign Connect — webhooks back to the record

As the envelope moves, Connect fires events your systems can consume. Status updates, completed documents, and recipient activity land on the same Salesforce, ServiceNow, or SharePoint record.

Connect event stream
  1. envelope-sent Recipients notified → Status: Sent
  2. envelope-delivered Recipients viewed in DocuSign → Status: Delivered
  3. envelope-completed All recipients completed → Status: Completed · PDF available
  4. recipient-completed One recipient finished → Update per-signer checklist

Beyond the first send

Iris extracts. Integrations deliver.

Not every agreement starts in a CRM. Vendor paper often arrives as a black box — teams hunt for parties, renewals, and risk by hand. Iris (with Agreement Manager) extracts structured terms from agreements; those values can then seed a renewal envelope or flow to downstream systems through Workflow Builder, Connect, or platform writeback.

01

Ingest

Vendor paper or a prior MSA lands in Agreement Desk / CLM — the document becomes the source of truth.

02

Extract

Iris identifies parties, contract value, renewal dates, governing law, and risk clauses automatically.

03

Act

Pre-fill a renewal envelope, or push extracted fields back into the system of record your teams already use.
